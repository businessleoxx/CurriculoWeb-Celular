# Currículo Web

Projeto de currículo pessoal em HTML, com uma página simples que apresenta resumo, formação, habilidades, idiomas e atalhos de contato e localização.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como visualizar

Abra `index.html` em um navegador. Para testar em um servidor local, execute na pasta do projeto:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000`.

## Estrutura

- `index.html`: conteúdo e marcação da página
- `style.css`: estilos visuais
- `script.js`: interações dos botões
